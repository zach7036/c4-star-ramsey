# The Ramsey number R(C₄, K₁,₅₁) = 59

**Claim.** R(C₄, K₁,₅₁) = 59, and consequently R(C₄, W₅₂) = 59.

Write f(n) := R(C₄, K₁,ₙ). Boza (arXiv:2409.12770v2, June 2026) lists f(51) ∈ {59, 60}
(Prop. 11 gives f(51) ≥ 59; Parsons gives f(51) ≤ 51 + ⌈√51⌉ + 1 = 60). Searches
through July 2026 found no later resolution.

Unlike our proof of f(39) = 46 — which needed either a 144-case exhaustive search or a
moment-LP dual certificate — this proof is **short, elementary, and fully human-checkable**.
Its only computational ingredient is evaluating 57 integers and observing that none is a
perfect square.

---

## 1. Lower bound

`lower_bound_58.json` contains a C₄-free graph on 58 vertices with δ = 7 = 58 − 51,
obtained by deleting 15 vertices from the polarity graph ER₈ of PG(2, 8) (GF(8) =
GF(2)[t]/(t³+t+1)). Verified directly by `verify_51.py`. Hence **f(51) ≥ 59**.
(This independently re-derives Boza's Prop. 11 bound; the same computation gives
59- and 60-vertex witnesses re-deriving f(52) ≥ 60 and f(53) ≥ 61.)

## 2. Reduction

f(51) ≤ 59 ⟺ no C₄-free graph on 59 vertices has δ ≥ 8. Suppose G is such a graph.

**Lemma A (regularity).** Counting vertices by distance from v (C₄-freeness makes the
neighbourhoods' outreach disjoint):
  Σ_{u∈N(v)} d(u) = 58 + 2m_v − f_v ≤ 58 + d(v),
where m_v = #edges inside N(v), f_v = #vertices at distance ≥ 3. Every neighbour has
degree ≥ 8, so 8d ≤ 58 + d, d ≤ 58/7 < 8.3, hence **G is 8-regular**.

**Lemma B (deficiency graph).** Let D be the graph on V(G) with u ~ w iff u ≠ w have
no common neighbour in G. Then deg_D(v) = f_v + (8 − 2m_v) — the distance-≥3 vertices
plus the neighbours joined to v by a triangle-free edge — and Lemma A's count gives
f_v = 2m_v − 6, so
  **deg_D(v) = 2 for every v: D is a disjoint union of cycles covering 59 vertices.**
Moreover A² = 7I + J − D (entrywise: common-neighbour counts are 1 − D_uv off the
diagonal), and since G is regular, A commutes with J and hence with D.

## 3. The spectral sign-balance argument

Diagonalise A and D simultaneously. On 𝟙 (all-ones): A𝟙 = 8𝟙, D𝟙 = 2𝟙. On 𝟙⊥, every
common eigenvector satisfies
  **θ² = 7 − μ, μ ∈ spec(D),**
and spec(D) is *explicit*: each cycle of length ℓ contributes {2cos(2πj/ℓ) : 0 ≤ j < ℓ}.
So μ ∈ [−2, 2] and θ² ∈ [5, 9].

Since A is an integer matrix, its characteristic polynomial lies in ℤ[x]: the spectrum
is a Galois-stable multiset. Classify the eigenvalues on 𝟙⊥:

**(i) Rational θ.** A rational algebraic integer is an integer, so θ² ∈ {5,…,9} must be
a perfect square: θ² = 9, i.e. **θ = ±3** (μ = −2, contributed once by each even cycle).
These multiplicities a (for +3) and b (for −3) are unconstrained by Galois theory.

**(ii) Rational μ, irrational θ.** μ ∈ {−1, 0, 1, 2} gives θ² ∈ {8, 7, 6, 5}, none a
square: x² − θ² is irreducible over ℚ, so +θ and −θ are conjugate and carry **equal
multiplicity** — contributing 0 to the trace. (μ = 2 has multiplicity c − 1 on 𝟙⊥,
c = number of cycles; the equal split forces c odd, a structural bonus not needed below.)

**(iii) Irrational μ.** Let μ have degree r ≥ 2 with conjugates μ₁,…,μ_r. If 7 − μ is
**not** a square in ℚ(μ), then θ = √(7−μ) has degree 2r, and its minimal polynomial —
being monic of degree 2r dividing Π᷈ᵢ(x² − (7−μᵢ)) — *is* that product. Its roots include
both ±√(7−μᵢ) for every i, all with equal multiplicity in any Galois-stable multiset:
contribution to the trace, **0**.

**(iv) The escape hatch, closed by computation.** If 7 − μ *were* a square α² with
α ∈ ℚ(μ) (α an algebraic integer), then taking norms,
  N_{ℚ(μ)/ℚ}(7 − μ) = ψ_d(7) = N(α)²
would be a perfect square in ℤ, where ψ_d is the minimal polynomial of 2cos(2π/d) and
d | ℓ for some cycle length ℓ ≤ 59. Using the identity
  Π_{j=0}^{d−1} (x − 2cos(2πj/d)) = V_d(x) − 2 (V₀ = 2, V₁ = x, V_d = xV_{d−1} − V_{d−2}),
which at x = 7 equals L₄d − 2 = 5F₂d² (Lucas/Fibonacci), Möbius inversion gives ψ_d(7)
exactly. **For every 3 ≤ d ≤ 59 with irrational μ, ψ_d(7) is not a perfect square**
(`psi_squares.py`; e.g. ψ₅(7) = 55, ψ₇(7) = 377 = 13·29, ψ₈(7) = 47, ψ₁₃(7) = F₂₆ =
233·521). So case (iv) never occurs.

**Conclusion.** The trace of A on 𝟙⊥ is 0 − 8 = −8, and by (i)–(iv) it equals 3(a − b):
  **3(a − b) = −8, impossible.**
No such G exists; f(51) ≤ 59; with §1, **R(C₄, K₁,₅₁) = 59**. ∎

## 4. Validation against ground truth

The identical argument was run on every z = 2 case with a known answer
(z := N − 1 − k(k−1) = 2 makes D always 2-regular):

| case | known status | argument's verdict |
|---|---|---|
| (15, 4) | **exists** (our explicit witness) | correctly silent: rational θ = ±1, ±2 available; witness's spectrum {4, 1, −1, 2², (−2)⁴, ±√5, (±√2)²} carries the trace −4 entirely on rational eigenvalues, with all irrational pairs sign-balanced — exactly as the theory prescribes |
| (23, 5) | impossible (f(18) = 23) | **closes**: only rational θ = ±2, trace −5 odd — an independent elementary re-proof |
| (45, 7) | impossible (f(38) = 45) | correctly silent: square cases exist — ψ₁₄(6) = 13², ψ₁₅(6) = 31² — so sign-balance alone cannot decide it |
| (59, 8) | **open** | **closes**: R(C₄,K₁,₅₁) = 59 |

The (45,7) row matters: it shows the square-case check has teeth, so the clean scan at
k = 8 is a genuine fact about Fibonacci-type numbers, not a vacuous test.

## 5. A second application: k = 10

The same argument at k = 10, N = 93 (z = 92 − 90 = 2): rational θ requires
θ² = 9 − μ ∈ {7,…,11} a perfect square — only θ = ±3 (μ = 0, arising from the
rational case d = 4; note ψ₄(9) = 9 = 3² is a square, but rational μ is handled
by the sign-balance dichotomy directly, never by the norm test) — and ψ_d(9) is
not a perfect square for any relevant irrational-μ order d ≤ 93
(`psi_squares.py`). So 3(a − b) = −10,
impossible:

> **No 10-regular C₄-free graph on 93 vertices exists.** Hence f(83) ≤ 93, improving
> Parsons' bound f(83) ≤ 94. (Whether f(83) = 93 depends on a lower-bound witness —
> a C₄-free graph on 92 vertices with δ ≥ 9 — currently unknown.)

## 6. Context: the sub-Moore programme

For k-regular C₄-free graphs on N = k(k−1) + 1 + z vertices, z = 0 is the friendship
theorem, z = k admits girth 5 (Moore graphs at f_v ≡ 0), and 0 < z < k forces heavy
triangle structure. Defining z*(k) = the least z admitting existence, known values plus
this work give:

  z*(3) = 3 (Petersen), z*(4) = 2, z*(5) = 5, z*(6) = 3, z*(7) = 5, **z*(8) ≥ 3**.

The trace argument explains a curiosity: at z = 2 the cases k ≡ 0 (mod 2) with only
θ = ±3 available die by 3 ∤ k — precisely k = 8 and k = 10, which were exactly the
z = 2 cases that had *resisted* other methods (k = 5, 7 fell to parity, k = 4, 6 admit
solvable trace equations, and k = 4 in fact exists).

## 7. What is and is not claimed

* The proof of f(51) = 59 is complete modulo standard algebraic number theory and the
  57-integer square check; no SAT, no LP, no floating point anywhere.
* Novelty is asserted only as "no prior resolution located" (Boza v2, June 2026, lists
  the case open; DS1 rev. 18 covers n ≤ 41; searches found nothing newer).
* The f(83) result is an upper bound only.
* Independent human review is still the appropriate final gate, as for f(39) = 46.
